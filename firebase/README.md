# Firebase integration

This directory is reserved for future cloud configuration and backend code. Firebase is not configured or deployed yet.

When integration begins, keep the Firebase CLI configuration, Firestore rules and indexes, Storage rules, backend functions, and their tests here. Keep application-side repositories in the Android module.

Document environment setup and deployment in the team wiki. Select the project's database, authentication, and image-storage services as part of that work. Do not add permissive placeholder rules or credentials to this skeleton.
